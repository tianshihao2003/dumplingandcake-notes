## 最高频快捷键（建议优先掌握）

这些是日常编码中使用最频繁的快捷键，能显著提升效率：

- `Alt + Enter`：意图操作与快速修复（自动导入、修复错误等）
- `Ctrl + B` 或 `Ctrl + 鼠标左键`：跳转到定义处
- `Shift + Shift`：全局搜索（文件、符号、操作）
- `Ctrl + Space`：基础代码补全
- `Ctrl + /`：注释/取消注释当前行
- `Ctrl + D`：复制当前行或选中的块
- `Ctrl + Y`：删除当前行
- `Tab / Shift + Tab`：缩进/取消缩进
- `Ctrl + F`：在当前文件中查找
- `Ctrl + R`：在当前文件中替换

## 其他实用快捷键

### 代码编辑与重构
- `Ctrl + Shift + Up/Down`：将当前行或代码块向上/下移动
- `Shift + F6`：重命名（自动更新所有引用）
- `Ctrl + Alt + T`：用 `if`、`try-except` 等代码块包围选中代码
- `Ctrl + Shift + Delete`：删除未使用的语句或包
- `Ctrl + Alt + B`：跳转到实现（对于接口或抽象方法）

### 运行与调试
- `Shift + F10`：运行当前配置的程序
- `Shift + F9`：调试当前配置的程序
- `F8`：单步跳过（Step Over）
- `F7`：单步进入（Step Into）
- `Shift + F8`：单步跳出（Step Out）
- `F9`：恢复程序运行（Resume Program）
- `Ctrl + F2`：停止当前运行/调试进程

### 视图与窗口
- `Ctrl + Tab`：在已打开的工具窗口和编辑器标签之间切换
- `Ctrl + G`：跳转到指定行号
- `Ctrl + +/-`：展开/折叠当前代码块
- `Ctrl + Shift +/-`：展开/折叠所有代码块

## 给初学者的建议

1.  **先熟练 `Alt + Enter` 和 `Shift + Shift`**，这两个能解决你初期大部分的“找不到功能”的问题。
2.  在编写循环或条件判断时，多用 `Ctrl + Alt + T` 来快速包裹代码块，能减少很多手动输入。
3.  养成用 `Ctrl + B` 查看定义的习惯，这有助于你快速理解库函数的用法。
4.  调试时，`F8` 和 `F7` 是你的得力助手，配合断点使用效果更佳。
