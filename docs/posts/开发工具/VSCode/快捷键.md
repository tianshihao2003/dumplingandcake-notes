# VSCode 快捷键

| 快捷键                 | 功能                                |
| ------------------- | --------------------------------- |
| `Ctrl + N`          | 新建文件                              |
| `Shift + Alt + F`   | 格式化整个文件                           |
| `Ctrl + K Ctrl + F` | 格式化选中的代码（先按住 Ctrl+K 松开后再按 Ctrl+F） |
