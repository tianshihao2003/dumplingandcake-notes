# VSCode 问题与技巧

## 快捷键按了没反应

### 常见原因排查

| 原因      | 判断方法                             | 解决办法                            |
| ------- | -------------------------------- | ------------------------------- |
| 输入法抢键   | 切英文输入法再试                         | 关闭中文输入法的快捷键拦截，或给VSCode单独配英文输入模式 |
| 快捷键冲突   | `Ctrl + K Ctrl + S` 搜索按键，看有无警告图标 | 修改冲突的快捷键                        |
| 焦点不在编辑器 | 检查快捷键的 `when` 条件                 | 用鼠标点击编辑器区域再试                    |
| 插件接管按键  | 刚装插件后失灵                          | 在快捷键面板搜索插件名，禁用或修改               |
| 笔记本F键问题 | 需要按住 `Fn` 键                      | 检查Fn锁定状态（`Fn + Esc` 锁定）         |

### When 条件不满足

VSCode 很多快捷键有 `when` 条件限制，比如 `workbench.editor.activeGroupCenter` 表示焦点必须在编辑器中心标签页。焦点在侧边栏、终端、通知栏时，这些快捷键不会响应（静默不执行）。

**验证方法**：在快捷键面板（`Ctrl + K Ctrl + S`）搜索按键，查看 `when` 列，确认当前焦点状态是否匹配。

## 快捷键面板使用

`Ctrl + K` 再按 `Ctrl + S` 打开快捷键面板：
- 搜索框支持按按键名称搜索（如输入 `ctrl+d`）
- 每行右侧显示 `when` 条件，可查看何时生效
- 右键可修改、禁用、导出快捷键配置
- 出现黄色警告图标表示有冲突

## Python 格式化程序

### 问题表现

按 `Shift + Alt + F` 格式化Python代码时弹窗提示：`没有安装用于"python"文件的格式化程序`

### 解决方案

推荐安装 **Black Formatter**（最流行的Python格式化工具）：

- 点击弹窗的「安装格式化程序...」→ 选择 Black Formatter
- 或手动安装：`Ctrl + Shift + X` → 搜索 `Black Formatter` → 安装 `ms-python.black-formatter`

安装后按 `Shift + Alt + F` 即可格式化Python代码。
