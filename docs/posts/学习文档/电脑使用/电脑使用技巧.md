# 怎么关闭笔记本电脑的自带鼠标滑动板？
## 方法：快捷键（最快）

大多数笔记本键盘上有一个带斜线的触摸板图标按键，按 `Fn` + 这个键即可切换开关。常见品牌对照：

- **联想**：`Fn + F6` 或 `F8`
- **戴尔**：`Fn + F3`
- **华硕**：`Fn + F9` 或 `F6`
- **惠普**：双击触摸板左上角，或 `Fn + F` 系列带图标的那颗键
- **华为/荣耀**：`Fn + F6`

具体以键盘上印的图标为准（一个小方块带一条斜杠）。
我的是`Fn + F10`
