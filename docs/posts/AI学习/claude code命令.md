> Claude Code 的命令统一以 `/` 开头，在输入框直接敲就能用。下面是按用途分组的常用命令速查。

## 一、会话管理

| 命令 | 作用 | 使用场景 |
|---|---|---|
| `/resume` | 恢复上次对话 / 切换历史聊天记录 | 关掉终端后想接着聊，输入后会列出历史会话供选择 |
| `/compact` | 压缩上下文 | 聊得太长时，把历史总结压缩，省 token 又能继续聊 |
| `/clear` | 清空上下文 | 彻底换话题，从零开始 |
| `/export` | 导出会话记录 | 把对话保存成文件留档 |

> 💡 想换话题又不想丢上下文，先用 `/compact` 压缩，比 `/clear` 一刀切更省。

## 二、状态与设置

| 命令 | 作用 |
|---|---|
| `/status` | 查看当前模型、模式、上下文用量 |
| `/cost` | 查看本次会话消耗的 token 和费用 |
| `/model` | 切换模型（弹出列表选择） |
| `/effort` | 调整努力程度，输入后按左右箭头切换 |
| `/permissions` | 切换权限模式（快捷键 `Shift+Tab`） |
| `/config` | 打开交互式配置 |
| `/login` | 登录 / 切换账号 |

## 三、项目管理

| 命令 | 作用 |
|---|---|
| `/init` | 首次进入项目时生成 `CLAUDE.md`，让 AI 记住项目规矩 |
| `/add-dir` | 把指定目录加入项目上下文 |
| `/doctor` | 诊断安装、配置、网络等问题 |

## 四、进阶玩法

| 命令 | 作用 |
|---|---|
| `/mcp` | 查看和管理 MCP 服务器（连接外部工具） |
| `/agents` | 管理子代理，多代理协作处理大任务 |
| `/review` | 审查最近的代码改动 |
| `/memory` | 查看 Claude 的记忆内容 |

## 五、日常最常用的几条

- **`/resume`** — 恢复上次对话，也是切换聊天记录的入口
- **`/compact`** — 上下文太长时压缩历史
- **`/effort`** — 命令行直接调整努力程度，`/effort` 后按左右箭头切换
- **`Shift+Tab`** — 切换权限模式（默认询问 / 自动接受编辑 / 仅计划模式），写代码时最常用的快捷键
- **`/status`** — 随时看当前模型和上下文用量，心里有数

> ⚠️ 权限模式用 `Shift+Tab` 切到「自动接受编辑」后，AI 改代码不再逐个询问，速度快很多，但改动前建议先看它准备干什么。
