## AI对话

- **接口地址**: `/api/chat`

- **请求方式**: `POST`

- **接口描述**: 与AI伴侣进行对话，服务端会自动加载该会话的历史消息，并调用DeepSeek大模型生成回复。每次对话会自动保存到会话文件中。

- **请求参数**:
> 内嵌电子表格（v1 不转换），token: TOFMsLihZhntaOtYpxEctQGrns5_m1KIEu

- **请求示例**:
```json
{
    "session_name": "2026-05-25_10-47-15",
    "message": "今天心情不太好",
    "nick_name": "小甜甜",
    "nature": "活泼开朗的东北姑娘，说话直爽，爱唠嗑，带点大碴子味儿，特别热情暖心"
}
```

- **响应参数**:
> 内嵌电子表格（v1 不转换），token: TOFMsLihZhntaOtYpxEctQGrns5_U3ZFWO

- **响应示例**:
```python
{
    "code": 200,
    "message": "请求成功",
    "data": "咋滴啦大兄弟？有啥不开心的跟姐说说，别憋着！🌸"
}
```

## 附录: 通用说明

### 状态码说明

> 内嵌电子表格（v1 不转换），token: TOFMsLihZhntaOtYpxEctQGrns5_yAgr1M

### 统一响应格式

所有API接口均返回以下统一格式:

```python
{
    "code": 200,
    "message": "提示信息",
    "data": null
}
```

- `code`: 状态码 (integer)，200 表示成功

- `message`: 提示信息 (string)

- `data`: 响应数据 (any)，具体结构见各接口定义
