## 条件判断

### if...else

```Python
if 要判断的条件:
    条件成立时, 要执行的操作1
else:
    条件不成立时, 要执行的操作2
```

### if...elif...else

```Python
# if...elif...else 结构
if 要判断的条件1:
    条件成立时, 要执行的操作1
elif 要判断的条件2:
    条件成立时，要执行的操作2    
elif 要判断的条件3:
    条件成立时，要执行的操作3   
else:
    所有条件不成立时, 要执行的操作4
```


## 模式匹配

``` python
match 表达式的值:
	case 值1:
		如果表达式的值为1,则执行该条
	case 值2:
		如果表达式的值为2,则执行该条
	case 值3:
		如果表达式的值为3,则执行该条
	case _:
		前面的都没有匹配上,则执行该条

```

- 应用场景:  基于某个变量的多个固定值进行分支判断时，可以使用match模式匹配
- case匹配<span style="color:#d83931">多个字面量</span>`case 值1 | 值2 | 值3:...`


## 循环

### while

```Python
# while语法结构
while 条件表达式: 
    循环体语句1
    循环体语句2
    ......
```

```Python
# while语法结构

while 条件表达式: 
    循环体语句1
    循环体语句2
    ......
else:
    条件为False，循环正常结束时执行
```

- 注意事项
	- 条件表达式的结果为布尔类型

### for循环

```Python
# for循环结构
for 元素 in 待处理数据集:
    循环体代码(对元素进行处理)
else:                    
    循环结束时, 执行的代码 
```

- break关键字的作用 ?
      不能够单独书写，只能出现循环中，表示<span style="color:#d83931">结束、跳出</span>的意思。
- continue关键字的作用 ?
      不能够单独书写，只能出现循环中，表示<span style="color:#d83931">中断本次</span>循环，直接进入下一次循环。

## range语句


> [!NOTE] 注意
> 
> - `range(..)`语句的作用是什么?
>     -  生成指定规则的数字序列
>     -  用法：
>         - range(end)
>         - range(start,end)
>         - range(start,end,step)

## `end`参数的作用

> [!NOTE] 注意
> `print("*", end=" ")` 中`end`参数的作用是指定`print()`函数在输出完内容后，结尾添加什么字符，默认为 `\n`，表示输出完毕后换行，如果不想换行，就可以自己指定`end`参数 （比如每一次输出后，结尾增加两个空格）。
