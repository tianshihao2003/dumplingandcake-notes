## break
不能够单独书写，只能出现循环中，表示<span style="color:#d83931">结束、跳出</span>的意思。
## continue
不能够单独书写，只能出现循环中，表示<span style="color:#d83931">中断本次</span>循环，直接进入下一次循环。
## end
`print("*", end="  ")` 输出完毕后换行，如果不想换行，就可以自己指定`end`参数 （比如每一次输出后，结尾增加两个空格）。
## match / case
模式匹配：`match 表达式的值:` 基于某个变量的多个固定值进行分支判断，`case 值:` 列出各匹配项，`case _:` 兜底所有未匹配情况。
## del
删除列表中指定索引的元素 `del nums[索引]`；删除字典中指定的键值对 `del dict1["key"]`。
## in / not in
`元素 in 列表` 判断元素是否存在于容器中，`not in` 相反，结果为布尔值。
## global
在函数中声明使用全局变量，使得可以在函数内部修改全局变量的值；要先声明，再使用。
## lambda
定义匿名函数：`lambda 参数列表 : 函数体`，用于简化单行表达式的简单函数（常作为高阶函数的参数）。
## def / return
`def 函数名(参数列表):` 定义函数；`return` 返回返回值并结束函数，只有返回功能没有打印功能，要输出需配合 `print()` 函数。
