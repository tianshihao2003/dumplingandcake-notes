## 案例2：用 ORM 做四种查询

- [ ] **我的答案**

**需求**

基于案例1的模型，在同一次会话里依次完成：

1. 查询全表，打印每一条 `AiMessage`
2. 只查 `role` 和 `content` 两列
3. 条件查询：`role == "user"` 的记录
4. 排序 + 分页：按 `id` 降序，取前 2 条

要求每步都写清楚：构造语句 → 执行 → 取结果（`.scalars()` 和 `.all()` 的区别要体现出来）。

```python

```

> [!success]- 参考答案
> ```python
> from sqlalchemy import select
>
> if __name__ == "__main__":
>     with Session(engine) as session:
>         # 1. 全表查询：先按「元组」取，再用 scalars 直接拿对象
>         rows = session.execute(select(AiMessage)).all()      # 每条是 (AiMessage,)
>         for r in rows:
>             print(r[0])
>
>         objs = session.execute(select(AiMessage)).scalars().all()
>         for e in objs:
>             print(e)
>
>         # 2. 只查部分字段
>         result = session.execute(select(AiMessage.role, AiMessage.content)).all()
>         for role, content in result:
>             print(role, content)
>
>         # 3. 条件查询
>         users = session.execute(select(AiMessage).where(AiMessage.role == "user")).scalars().all()
>         for u in users:
>             print(u)
>
>         # 4. 排序 + 分页：ORDER BY id DESC LIMIT 2
>         top2 = session.execute(
>             select(AiMessage).order_by(AiMessage.id.desc()).limit(2)
>         ).scalars().all()
>         for t in top2:
>             print(t)
> ```

## 案例3：更新与删除（两种更新方式都要写）

- [ ] **我的答案**

**需求**

1. 方式一：用 `update(...).where(...).values(...)` 把 `id=1` 的 `content` 改成「你好」，`create_time` 改成当前时间，`commit()`
2. 方式二：用 `session.get(AiMessage, 3)` 取出对象，直接改属性再 `commit()`
3. 删除 `id=10` 的记录
4. 批量删除 `id` 为 7 和 11 的记录
5. 说明两种更新方式分别适合什么场景

```python

```

> [!success]- 参考答案
> ```python
> from sqlalchemy import update, delete
>
> if __name__ == "__main__":
>     with Session(engine) as session:
>         # 方式一：一条 UPDATE 直接改，适合按条件批量更新
>         session.execute(
>             update(AiMessage)
>             .where(AiMessage.id == 1)
>             .values(content="你好", create_time=datetime.now())
>         )
>         session.commit()
>
>         # 方式二：先查对象再改属性，适合按主键改单条
>         obj = session.get(AiMessage, 3)
>         obj.content = "大家下午好"
>         obj.create_time = datetime.now()
>         session.commit()
>
>         # 按 id 删单条
>         session.execute(delete(AiMessage).where(AiMessage.id == 10))
>
>         # 批量删：id 为 7 或 11
>         session.execute(delete(AiMessage).where(AiMessage.id.in_([7, 11])))
>         session.commit()
> ```
>
> 场景对比：**方式一只打一次数据库**，适合条件批量更新；**方式二查一次、改一次共两次**，适合按主键改单条，但能用对象做业务判断。
