## 案例2：Pydantic 模型约束返回结构

- [ ] **我的答案**

**需求**

1. 用 Pydantic 定义一个 `User` 模型：`id`（整数）、`name`（字符串）、`age`（整数，可选，不传时为 `None`）
2. 写接口 `GET /users`，返回 3 个 `User` 对象组成的列表，其中至少一个不传 `age`
3. 用 `response_model` 声明返回值类型
4. 把 `age` 传成字符串 `"18"` 试一次，观察 FastAPI 是报错还是自动转换

```python

```

> [!success]- 参考答案
> ```python
> from fastapi import FastAPI
> from pydantic import BaseModel
>
> app = FastAPI()
>
> class User(BaseModel):
>     id: int
>     name: str
>     age: int | None = None      # 可选属性，不传就是 None
>
> @app.get("/users", response_model=list[User])
> def get_users():
>     return [
>         User(id=1, name="Alice", age=18),   # Pydantic 必须关键字传参
>         User(id=2, name="Bob"),             # 不传 age
>         User(id=3, name="Charlie", age="25"),  # "25" 会被转成 int 25
>     ]
> ```

3. 启动后打开 `http://localhost:8000/docs`，确认首页能看到项目描述、两个接口分组正确、可以直接在页面上点「Try it out」调通

```python

```

> [!success]- 参考答案
> ```python
> from fastapi import FastAPI
> from pydantic import BaseModel
> import uvicorn
>
> class User(BaseModel):
>     id: int
>     name: str
>     hobby: str
>

>     title="FastAPI 入门",

## 案例4：同步接口 vs 异步接口的耗时对比

- [ ] **我的答案**

**需求**

1. 写一个「模拟查数据」的函数：打印开始、等待 3 秒、打印完成
2. 写两个接口：
   - `GET /sync_demo`：同步方式连续调用 3 次，返回总耗时
   - `GET /async_demo`：异步方式让 3 个任务同时跑，返回总耗时
3. 分别访问两个接口，比较耗时（同步约 9 秒，异步约 3 秒）
4. 把 `/async_demo` 里的 `async def` 去掉、`await` 保留，启动看报什么错

> import time
