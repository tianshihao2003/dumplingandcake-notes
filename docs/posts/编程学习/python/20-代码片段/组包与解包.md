## 组包

多个值用逗号隔开，会自动封装成一个元组（逗号才是元组的灵魂，括号只是装饰）：

```python
t2 = 5, 7, 9, 1   # t2 为 (5, 7, 9, 1)
```

## 基础解包

```python
t1 = (5, 7, 9, 1)
a, b, c, d = t1   # 变量数量要和元素数量一一对应
```

## (*)扩展解包

带 `*` 的变量把多余的元素收进一个列表：

```python
t2 = 5, 7, 9, 1
x, *y, z = t2   # x为5, y为[7, 9], z为1
s, *o = t2      # s为5, o为[7, 9, 1]
*o, e = t2      # o为[5, 7, 9], e为1
```

## 应用

（换种需求怎么改：合并列表时用解包展开）

```python
num_list = [*num_list1, *num_list2]   # 用 + 也能合并, 但解包可以和别的元素混着拼
```
