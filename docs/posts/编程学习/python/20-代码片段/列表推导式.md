## 语法

```python
# 格式1: 直接生成
新列表 = [要插入的值 for i in 容器]

# 格式2: 带 if 过滤
新列表 = [要插入的值 for i in 容器 if 条件表达式]
```

## 样例

```python
new_list01 = [i**2 for i in range(1, 21)]                # 1~20 的平方
new_list02 = [i**2 for i in range(1, 21) if i % 2 == 0]  # 只要偶数的平方
```

## 变体

（换种需求怎么改：for 后面加 if 是过滤；要"二选一转换"时把 if 写到值的位置）

```python
# if-else 转换: 条件成立取值1, 否则取值2
new_list03 = [i if i % 2 == 0 else 0 for i in range(1, 21)]
```
