## 语法

```python
容器名[开始索引:结束索引:步长]   # 含头不含尾
```

## 样例

```python
s = ["A", "C", "E", "B", "D"]
s[0:5]      # 取全部
s[-5:-1]    # 负数索引同样适用
```

字符串切片同理：`序列对象[开始索引:结束索引:步长]`

## 坑 / 容易写错的参数

- 只有**有序、有索引**的容器能切片：列表、字符串、元组可以；集合（无序）、字典（无索引）不行。
- 结束索引是"取不到"的边界，不是最后一个元素的位置。
