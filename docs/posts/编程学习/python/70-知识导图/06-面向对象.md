  - 面向对象进阶
    - 三大特性：封装、继承、多态
      - 封装
        - 将数据和方法私有化
        - 对外提供开放接口访问
        - 知识小拓展：私有的本质是改名
      - 继承
        - class 子类(父类)
	        - `super().__init__()`
        - 方法的重写
	        - super().父类的方法/属性
	        - `父类名.方法名(self)`
        - 多继承
	        - class 子类名(父类名1, 父类名2, 父类名3, ...)
	        - 父类相同的方法，按继承顺序使用->
      - 多态
        - 调用一个有父类参数的方法，子类重写==>不同形态
        - 鸭子类型
      - 抽象类
	      - 有抽象方法的类
	      - 继承ABC父类
	      - @abstractmethod修饰抽象方法
	      - 导入from abc import ABC, abstractmethod
  - 异常
    - 捕获异常，防止程序直接崩溃，给程序容错能力
    - 多异常处理
	    - 设置多个except分别捕获处理
    - Python中的异常体系结构
  - 文件操作

    - 释放资源

    - 路径写法
      - 相对路径语法

    - json操作
