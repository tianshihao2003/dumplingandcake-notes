- 04-模块
    - 模块入门
	    - module
	    - 自定义模块
	    - 内置模块
      - 导入模块
	      - import 模块名
	      - import 模块名 as 别名
	      - from 模块名 import 功能名
	      - from 模块名 import 功能名 as 别名
	      - from 模块名 import*
  - 模块进阶操作
    - 自定义模块
	    - py文件
    - 自定义模块导入
	    - `__all__`：模块级，指定导入哪些功能
	    - `__nmae__`当前模块的名字
		    - 当前模块：main
		    - 别导入时：模块文件名（不带py）
		    - if `__nmae__`\=="main"
  - 软件包(package)
    - 本质是一个文件夹
    - 管理模块
    - `__init__`：包级
	    - 描述信息
	    - 作者
	    - 版本
	    - 指定import\*导入的模块
    - 包的导入方式
	    - import 包名.模块名
	    - from 包名 import 模块名
	    - from 包名 import\*
	    - from 包名.模块名 import 功能名
	    - from 包名.模块名 import \*
	- 注意事项
	    - 普通文件夹无法作为包导入
	    - 通过from 包名 import \* 导入时必须在`__init__.py`中添加`__all__[]`
