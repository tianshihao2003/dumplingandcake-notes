		- 字面量与变量
			- 字面量
				- 指程序中直接书写的固定值
				- 比如：99、“Hello”
			- 变量
				- 存储单个变量的容器
				- 格式：变量名 = 变量的值
			- 标识符
				- 程序员在程序中为变量、函数、类等元素起的名字
				- 命名规则
					- 只能包含字母、数字、下划线
					- 不能以数字开头
					- 不能使用关键字
					- 严格区分大小写
		- 数据类型
			- 常见的数据类型

			- 类型转换函数
