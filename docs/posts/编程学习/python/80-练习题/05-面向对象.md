### 编写一个 `Phone` 手机类：

1. 实例属性：品牌 brand，`__price`（价格私有化）
2. 方法：
    - `show_info()`：打印品牌和价格（在类内部访问私有属性）
    - `set_price(new_price)`：修改价格，校验规则：价格必须大于 0、小于等于 10000，不符合则输出`价格不合法`
3. 测试代码：
    - 创建手机对象：小米，初始价格 2999
    - 调用 show_info () 查看信息
    - 尝试修改价格为 12000
    - 再修改价格为 3999
    - 再次调用 show_info () 查看信息

我的答案：
```py
class Phone:  
    def __init__(self,brand,price):  
        self.brand=brand  
        self.__price=price  
  
    def show_info(self):  
        print(f"{self.brand}的价格为:{self.__price}")  
  
    def set_price(self,price):  
        if price>0 and price<=10000:  
            self.__price=price  
        else:  
            print("输出不合法")  
  
xiaomi = Phone("xiaomi",2999)  
xiaomi.show_info()  
  
xiaomi.set_price(12000)  
xiaomi.set_price(3999)  
  
xiaomi.show_info()
```
