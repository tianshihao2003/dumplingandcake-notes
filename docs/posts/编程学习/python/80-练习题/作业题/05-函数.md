## 作业一：定义一个函数，根据传入的分数，计算对应的分数等级并返回。 ❌

> [!question]- 题目
>
> 函数基础作业 [必做]
>
> 1. 定义一个函数，根据传入的分数，计算对应的分数等级并返回。
>   1. 分数 >= 90：A
>   2. 分数 >= 75：B
>   3. 分数 >= 60：C
>   4. 分数 < 60：D

- [x] **我的答案**

> [!example]- 我的答案
> ```python
> def score_organize(score):  
>     if score > 90:  
>         return "A"  
>     elif score > 75:  
>         return "B"  
>     elif 0 < score < 60:  
>         return "C"  
>     else:  
>         print("输入错误")  
>         return None  
>
>
> print(score_organize(100))
> ```

> [!success]- 参考答案
> ```python
>
> # ============================================================================
> # 练习1：根据分数计算等级
> # ============================================================================
> """
> 【需求说明】
>     定义一个函数 calculate_grade，根据传入的分数，计算对应的等级并返回。
>
>     等级规则：
>         分数 >= 90 : A
>         分数 >= 75 : B
>         分数 >= 60 : C
>         分数 <  60 : D
> """
>
> def calculate_grade(score):
>     """
>     根据分数计算并返回对应等级
>     :param score: 分数（int / float）
>     :return: 等级（str），取值为 "A" / "B" / "C" / "D"
>     """
>     if score >= 90:
>         print("A)
>     elif score >= 75:

> print("=" * 50)
>

> for s in test_scores_1:
>     calculate_grade(s)

> ```

**批改**

- [ ] ❌ 有问题

- 错在哪（边界全错，实测）：
  - `score > 90` 应为 `>= 90`：90 分被判成 B。
  - `elif 0 < score < 60: return "C"` 区间写错：59 分被判成 C（应 D）。
  - 60~75 之间没有分支，落到 else 输出「输入错误」并返回 None：实测 75、70、60 都是 None。
- 正确写法：

```python
if score >= 90:
    return "A"
elif score >= 75:
    return "B"
elif score >= 60:
    return "C"
else:
    return "D"
```

- 原因：等级是「大于等于」的连续区间，从高往低写一条链就够，不用另拆 `0 < score < 60`。

```python
def calc_order_cost(*goods, coupon=0, score=0, freight=0):

        total -= min(coupon, total)
        total -= min(score // 100, total)
    return total + freight
```
