## day01

1). Python中的标识符定义规则是什么 ，请描述一下 。

::: details 答案

标识符是给<span style="color:#ff0000">变量、函数、类、模块等起的名字</span>，规则如下：
	- 组成：只能由<span style="color:#0070c0">大小写字母、数字、下划线（_）</span>构成
	- 限制：<span style="color:#0070c0">不能以数字开头</span>，不能和 Python 内置关键字重名
	- 特性：<span style="color:#0070c0">严格区分大小写</span>
	- 规范：**见名知意**，不建议使用中文命名（虽语法支持，但不符合工程规范）

:::


2). 请描述一下Python中常见的数据类型有哪些？ 字符串在进行拼接或格式化时，有哪些方式 ？


::: details 答案

常见内置数据类型：
- 基础标量类型：整数 int、浮点数  float、布尔值 bool、字符串 str、空值 None
- 容器类型：列表 list、元组 tuple、集合 set、字典 dict

字符串拼接/格式化常用方案：
- 使用 + 号连接
- % 占位符格式化
- f-string 格式化

:::

<span style="color:#000000">4). 请描述一下什么是逻辑运算符，逻辑运算符有哪几个？ 具体的含义是什么？</span>

::: details 答案

是编程语言中用于组合多个布尔判断条件、推导最终真假结果的运算符号
Python共包含3个逻辑运算符：
- and（逻辑与/并且）：有0为0
- or（逻辑或/或）：有1为1
- not（逻辑非/取反）：条件结果反转

补充面试高频考点：
Python逻辑运算符的返回值不一定是布尔值，会直接返回触发短路的操作数本身，比如 3 and 5 返回 5、0 or "abc" 返回 "abc"
<span style="color:#d83931">注意区别于比较运算符</span>

:::

## day02

1、请叙述下，条件判断第三种格式完整的执行流程（if 条件1...elif 条件2... elif 条件3... else）

::: details 答案

`if-elif-else` 是多分支条件判断结构。程序会从上到下依次判断每个条件，一旦某个条件为 True，就执行该条件对应的代码块，执行完后直接跳出整个结构，后面的 `elif` 和 `else` 不再判断。如果所有 `if` 和 `elif` 条件都为 False，则执行 `else` 分支。

它的特点是顺序判断、短路执行，并且整个结构最多只会执行一个分支。

:::



2、请叙述下，while循环完整的执行流程 
     变量定义   
     while  条件 
         循环体
         变量更新

::: details 答案

`while` 循环的执行流程是：先<span style="color:#d83931">定义并初始化</span>循环变量，然后判断 `while` 条件。如果条件为 True，就执行循环体；循环体执行完后执行变量更新，再回到条件判断处重新判断。直到当条件变为 False 时，退出循环，继续执行循环后面的代码。

它属于先判断后执行的循环，如果第一次条件就为 False，循环体一次也不会执行。实际使用时要注意变量更新，避免死循环。

:::


3、请说一下什么时候使用无限循环，如果需要结束无限循环了怎么办？可以举个例子

::: details 答案

无限循环一般用在循环次数事先不确定、需要持续监听、持续交互或者失败重试的场景，常见写法是 `while True`。它并不是没有退出条件，而是退出条件通常放在循环体内部判断。结束无限循环最常用的是 `break`

如果循环在函数里也可以用 `return`，程序需要整体退出可以用 `sys.exit()`，异常场景可以 `raise`。

比如做一个命令行菜单，用 `while True` 持续等待用户输入，当用户输入 `exit` 时执行 `break` 退出循环。实际开发中要注意保证有明确的退出路径，避免真正的死循环。

:::


4、分别说一下range(end),range(start,end)，range(start,end,step) 取值范围

::: details 答案


`range` 的取值范围遵循左闭右开原则。
`range(end)` 等价于 `range(0, end, 1)`，取值是 0 到 end-1；
`range(start, end)` 等价于 `range(start, end, 1)`，从 start 开始到 end-1 结束；
`range(start, end, step)` 从 start 开始，每次增加 step，直到不包含 end 为止。

如果 step 是正数，要求 start 小于 end；
如果 step 是负数，要求 start 大于 end；
step 不能为 0。
它返回的是 range 对象，是惰性序列，不是列表。

:::
