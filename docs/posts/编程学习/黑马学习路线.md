# 黑马「AI 应用与智能体开发 V6.0」完整路线图

> 来源：黑马程序员《AI 应用与智能体开发 V6.0》课程大纲（46 页）。总课时 85 天，8 个阶段，技术主线是 **Java 企业级开发 + Python/AI 工程 + 大模型落地** 三线合一。

## 一、总览

| 阶段  | 名称                      | 天数  | 关键产出                                    |


## 二、阶段详解

### 第一阶段：Vibe Coding 零代码 AI 应用开发（9 天）

**定位**：不写代码，先建立「智能应用 = 前端 + 后端 + Agent + 大模型」的整体架构认知，用 Coze 把完整智能体跑通并发布。

**学习目标**

1. 掌握 AI 应用开发的整体架构（前端 → 后端 → Agent → 大模型）
2. 掌握人工智能、模型、大语言模型、推理模型、多模态模型及 token 计费等基础概念
3. 能运用提示词工程五大原则写出高质量提示词
4. 能利用 Vibe Coding 编写简单的 AI 应用
5. 掌握 Coze 平台中工作流、插件、知识库、数据库等核心资源的使用
6. 能搭建并发布完整智能体（提示词编写、工作流添加与调试、多渠道发布）
7. 能在工作流中实现知识库检索与数据库增删改查、处理私有数据
8. 能使用图像、音频、视频等多模态节点或插件处理多模态数据
9. 能使用循环节点批量处理任务并优化模型效果

**章节与技术点**

#### 1. 初识智能应用开发

- 什么是智能应用开发
- 大模型本身的弊端
- 企业中智能模块的解决方案
- 什么是智能体
- 智能体的四个关键能力
- 智能应用的整体软件架构
- 开发智能模块时需要学习的内容
- 利用 AI 参与开发我们要面对的问题

#### 2. 人工智能通识

- 人工智能的定义
- 人工智能的四个期望
- 模型和目前市面上模型的分类
- Token（词元）和大模型分割的方式
- Vibe Coding（氛围编程）的介绍
- Vibe Coding 环境搭建

#### 3. 提示词工程

- 提示词
- 提示词工程
- 大模型幻觉
- 提示词工程的五大原则（清晰指令、文本参考、拆分任务、给思考时间、借助外部工具）
- 清晰指令的五大技巧
- 提示词的否定指令陷阱
- 大模型的 Skill 技能

#### 4. 基于平台的智能体（Coze）

- Agent 智能体的定义 / 实现智能体的技术栈
- Coze 平台介绍和注册、常用模块
- 工作流：实现步骤、试运行、执行日志、Coze 中的节点、发布
- 搭建 Coze 智能体、智能体预览与调试
- 知识库与数据库：文档解析与分段、知识库存储选项与检索节点、扣子数据库的具体使用
- 大模型润色与兜底
- 多模态数据处理概述

### 第三阶段：RAG 智能体开发（10 天）

**定位**：企业级 AI 应用框架入场。LangChain 核心组件 → RAG 全链路 → LangGraph 复杂编排 → Linux + Docker 部署。

**学习目标**

1. 掌握 LangChain 框架核心组件用法，能用它开发智能体
2. 掌握 LangGraph 核心概念与组件用法，能实现复杂 Agent 工作流编排
3. 掌握向量知识库 Milvus 的用法
4. 掌握 RAG 系统基本原理和实现方法
5. 从零搭建一个 Multi-Agent 智能客服
6. 掌握 Linux 常见命令，会用 Docker 部署 AI 应用

**章节与技术点**

#### 1. LangChain

`认识 LangChain`、`Models（模型）`、`Messages（消息）`、`Prompts`、`Tools（工具）`、`Memory（记忆）`、`Runtime（运行时上下文）`、`Middleware（中间件）`、`MCP`、`Multi-Agent`

#### 2. RAG（检索增强生成）

`RAG 原理`、`Document Loader（文档加载）`、`Text Splitter（文档切分）`、`Embedding Model（向量模型）`、`Vector Store`、`Milvus`、`Retrievers（数据召回）`、`RAG 的多种模式`、`RAG 系统评估`

#### 3. LangGraph

`概述`、`核心概念（Node / Edge / Start / End / StateGraph）`、`流程编排`、`MultiInput 工作流`、`Sequence 工作流`、`ConditionalGraph 工作流`、`LoopingGraph 工作流`、`ReAct Agent 模式`、`Evaluator-optimizer`、`Parallelization 模式`、`Routing 模式`、`项目案例`

#### 4. AI 项目部署

- Linux：概述与安装、常用命令、软件安装、项目部署
- Docker：课程介绍、安装、快速入门（部署 MySQL、命令解读）、常见命令、操作案例、数据卷挂载、本地目录挂载、Dockerfile 语法、自定义镜像、容器网络互连、项目部署、Docker Compose
