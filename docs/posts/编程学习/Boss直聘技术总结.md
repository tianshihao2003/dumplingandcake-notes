# Boss直聘 Java 岗位技术需求总结

> 数据来源：同目录 `Boss直聘技术记录.md`，共 11 份杭州 Java 后端岗位 JD（10–50K，应届到 5 年）。

## 一、一句话结论

**Java + Spring 生态 + MySQL/Redis 是入场券；分布式、高并发、JVM 调优决定薪资档位；AI Coding 已从"加分项"变成明写的硬性要求。**

## 三、能力分层

### 1. 硬性门槛（几乎必问）

- **Java 基础**：集合、异常、IO/NIO、多线程、面向对象、设计模式、通信协议
- **Spring 全家桶**：Spring Boot 业务开发、Spring MVC、Spring Cloud 微服务
- **MySQL**：SQL 复杂查询与优化、索引设计、事务
- **Redis**：缓存用法、缓存与数据库一致性
- **消息队列**：Kafka / MQ 的常见用法与可靠性保障

### 2. 中高级分水岭

- **分布式与微服务**：服务拆分、Dubbo、注册中心、链路协作
- **高并发与稳定性**：幂等、并发控制、数据一致性、限流降级
- **架构设计**：模块职责划分、技术方案设计、复杂业务抽象
- **JVM 与性能**：JVM 原理、内存模型、性能优化与线上定位
- **数据规模**：分库分表、分区策略、索引优化、任务调度
- **工程规范**：单元测试、代码审查、CI/CD、技术文档、控制重复代码

### 3. AI 能力（新增的高频项）

- **AI 辅助开发工具链**：Claude Code、Codex、Cursor、ChatGPT、GitHub Copilot
- **AI 产出质量把关**：识别 AI 幻觉、逻辑错误、安全漏洞；提供上下文、拆解任务、验证与修正
- **大模型工程化**：Spring AI / Spring AI Alibaba、LangChain / LangChain4j、LangGraph
- **RAG 与 Agent**：RAG 切片与量化评估、提示词管理、结构化输出、Agent 落地方式
- **平台与部署**：Dify、Coze、百炼；vLLM / Ollama 部署排障；Mem0 / MemGPT 记忆框架

### 4. 业务与软技能

- 主动澄清需求、识别边界情况，把需求转成可靠的技术实现
- 跨团队协作（产品、前端、设计），对最终交付的代码质量负责
- 端到端 Owner 意识；组长岗还需团队管理与项目进度把控
- 行业合规意识：数据安全法、个人信息保护法（可信数据空间、隐私计算类岗位）

## 四、薪资档位对照

| 档位     | 典型要求                                                  |
| ------ | ----------------------------------------------------- |
| 10–15K | Java + Spring + MySQL 基础扎实，会用 AI 工具提效即可               |
| 15–25K | 加分布式 / Redis / MQ / 并发，AI Coding 写成明确要求，能独立完成模块       |
| 25–50K | 架构设计 + JVM 调优 + 大数据量或 AI 工程化（RAG / Agent / 模型部署），或带团队 |

## 五、按优先级补短板

1. **第一优先**：Java 基础 + Spring Boot 业务闭环 + MySQL 索引事务 + Redis 缓存（面试必问，门槛）
2. **第二优先**：消息队列 + 分布式与微服务 + 幂等/并发/一致性（跨过 15K 的关键）
3. **第三优先**：Spring AI / LangChain 跑一个 RAG + Agent 小项目，同时把 AI Coding 工具链用熟（差异化，也是当下 JD 的加分主轴）
4. **长期**：JVM 调优、分库分表、架构设计与技术文档能力（决定 25K 以上天花板）

> 补充：记录里零散提及的一次性技术（HBase、MongoDB、Oracle、C++/C/Go、Vue、Nginx、SVN）属于岗位个体差异，按目标公司再单独补。
