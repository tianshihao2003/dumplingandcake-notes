# note-organizer 使用说明

> 这篇是 `note-organizer` 技能的**能力清单**，写给人看。
> 技能规则在 `.agents/skills/note-organizer/SKILL.md`，两边必须保持一致——改了技能就要同步改这里。

## 它能做什么

| 能力 | 怎么说 | 结果落在哪 |
| --- | --- | --- |
| 同步讲义 | 「同步讲义」「下载今天的讲义」 | 更新 `50-归档/下载下来的飞书讲义/` 下的讲义、作业、参考答案 |
| 迁移作业 | 「整理 day10 的作业」「迁移作业」 | `80-练习题/作业题/<那天笔记同名>.md` |
| 出题（加练） | 「出 day10 的题」「加练」 | `80-练习题/AI生成加练题/<那天笔记同名>.md` |
| 批改 | 「批改作业」「批改 day10」 | 就地改上面三个目录里的同名文件，不新建文件 |

两个 AI 目录的区别：

- **`AI作业补充题/`** —— 迁移作业时顺手生成。只针对**作业内容特殊**的情况（比如作业只写「把课上案例全部搞定」，没有具体题面），把它拆成课堂案例实操题
- **`AI生成加练题/`** —— 我要额外加练时才生成，五道题四级梯度

## 它不做什么

**笔记和知识导图都是我自己整理**，技能不碰。

- 不写 `90-文档记录/`
- 不生成 `70-知识导图/`
- 不动 `30-概念卡`、`20-代码片段`、`10-卡点本`、`40-日志`、`60-面试题`
- 不做复习计划、不记日志、不跑 `pnpm build`

## 典型用法

### 1. 上课前后同步

```
同步讲义
```

两条导出命令各跑一次，未改动的文档秒跳过。它不会加 `--scope space`，避免把无关知识库拉进来。

**同步完会自动自检**：失败数、`_errors.md`、当天三件套是否齐全、正文里有没有「内嵌电子表格（v1 不转换）」这类导不出的块、图片是否都落地。发现缺失会**先重跑一遍**（增量补漏），仍然缺的会列成清单告诉你缺哪篇、缺什么，不会自己编内容。

### 2. 把今天的作业搬成练习文件

```
整理 day10 的作业
```

产出：一道题一个小节，每节有 `- [ ] **我的答案**` 空块、折叠参考答案、`（待批改）` 位置。
小问会拆开（`### 1.1`、`### 1.2`），但「做完这步才能做下一步」的项目式作业不拆。

### 3. 加练

```
出 day10 的题
```

两种题：
- **案例实操题**：作业写的是「把课上案例全都搞定」时，从当天讲义里抽课堂案例，改成动手题
- **补充练习**：五道，从照抄到组装四级梯度

### 4. 做完让我批

```
批改 day10
```

- 我的代码一个字不删，只在下面写结论
- 错题标题加 `❌`，结论开头是 `- [ ] ❌ 有问题`，我改好后自己勾上表示解决
- 批完题目和我的答案会自动折叠起来，只留结论在外面

## 文件命名规则

作业题、作业补充题、加练题都**跟当天笔记同名**：

```
90-文档记录/10-AI应用实战功能实现.md
80-练习题/作业题/10-AI应用实战功能实现.md
80-练习题/AI作业补充题/10-AI应用实战功能实现.md   ← 作业特殊时才有
80-练习题/AI生成加练题/10-AI应用实战功能实现.md   ← 要加练时才有
```

那天还没写笔记时，用 `NN-主题.md`，NN 取讲义天号。

## 常见问题

**Q：作业里有些表格是空的？**
A：飞书导出器对「内嵌电子表格」支持不全，导不出来的地方会保留原行并标 `[待补充]`，不会瞎编。

**Q：参考答案和题目对不上？**
A：那份题会标 `[待补充]`，答案不会自己写。

**Q：能不能顺便把笔记也整理了？**
A：不能。这是明确写进技能的禁止项，笔记由我自己写。
